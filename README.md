# Mashinani Link – Community Infrastructure Reporting System

## Description

Mashinani Link is a web-based platform designed to improve communication between residents and administrators by making it easier to report and follow up on community infrastructure problems.

Residents can submit reports about issues such as damaged roads, broken streetlights, drainage problems, and other community concerns. Administrators can view submitted reports, review them, and update their progress.

The project aims to make community issue reporting more organized, accessible, and transparent.

---

## How It Works

1. Residents visit the platform through the homepage.
2. Residents use the report page to submit community infrastructure issues.
3. Each submitted report is assigned a unique tracking ID.
4. Residents use the tracking page to check the status of their reports.
5. Administrators access the dashboard to view and manage submitted reports.
6. Administrators can search for reports and update their status.

## Setup Instructions

### 1. Clone the Repository

```bash
git clone git@github.com:Majuridev/mashinani-link-frontend.git
cd mashinani-link-frontend
```

### 2. Open the Project

```bash
code .
```

### 3. Start the Frontend Server

```bash
python3 -m http.server 8000
```

### 4. Open the Application

Open your browser and visit:

```text
http://localhost:8000
```

You can now navigate through the homepage, report page, tracking page, login page, and admin dashboard.
